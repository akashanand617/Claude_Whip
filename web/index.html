Calibration

Every tracking session starts with a 3 s pose so the console learns which way round the ring is on. No event is shown until the pose is accepted.

  • hold still
  • fingers pointing straight at the floor
  • keep it for 3 s

How: let the arm hang at your side, relax the hand so the fingers point at the floor, and do not move. Then bring the hand back up slowly, so the lift is not read as a flick up.

Events

one event per movement; each shows how long after its onset it was decided (about 1 s for a flick or snap, up to 2 s for a double)
